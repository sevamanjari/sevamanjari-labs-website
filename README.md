# SevaManjari Labs Private Limited — Next.js Website

Responsive corporate website built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## Run locally

Install Node.js LTS if needed: https://nodejs.org/

Open Command Prompt / PowerShell in this project folder and run:

```bash
npm install
npm run dev
```

Then open http://localhost:3000

For production:

```bash
npm run build
npm run start
```
